# Ten-percent teacher warm-start experiment

Interpret 10% as 600 of the balanced teacher's 6,000 optimizer updates, not a blend of random and trained weights. The original run saved every 2,000 updates, so reconstruct the first 600 updates from its exact saved random ancestor, seed 200, class-balanced MNIST batches, RNG seed 10200, batch 128, geometry cycle 32/40/56, Adam 3e-4, clipping norm 1, and EMA 0.999. Save both online and EMA weights at update 600. Continue the reconstruction to update 2,000 to compare with the first original saved checkpoint: report data-RNG identity and tensor differences for both online and EMA weights. Label numerical reconstruction honestly if tensors differ. Initialize students with the **online** weights at update 600; reset Adam rather than inheriting teacher momentum. The final teacher remains the unchanged balanced EMA generator at update 6,000.

The starting model has already received 76,800 real-digit presentations. Measure it before distillation; success here means improving this partially trained model's generation capability. It does not establish acquisition from a model with no digit exposure. Record ten-class diversity as well as the frozen noise-aware evaluator's acceptance rate.

Run two matched arms from identical update-600 weights: (1) true balanced-teacher border targets on Gaussian inputs and (2) the same residual-shuffled border-target control used in the random-start experiment. Freeze the update-600 model as the no-further-training baseline. All distillation inputs, teacher targets, 65,536 unique query identities, Gaussian center distribution, border channels, per-pass permutations, batch 64, Adam 1e-4, zero weight decay and clipping norm 1 match the random-start 56-canvas experiment. Distillation receives no MNIST images, center velocity targets, evaluator feedback or teacher parameter copies beyond the requested initialization. Use online student weights, with no EMA.

Run 16 passes (16,384 updates, 1,048,576 query presentations) per arm. Validate after passes 1,2,4,8,16 on the same 256 fixed noises as the random-start run. Evaluate the frozen starting model and final students on the common 2,000-noise endpoint bank, saving all per-image decisions and unfiltered images 0–63. Report paired image-sampling differences against the frozen start and shuffled control. They do not measure training-seed uncertainty. Check 50/100-step sampler agreement for the starting model and any final student with at least 20% acceptance.
