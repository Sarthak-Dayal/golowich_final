## Experiment 1 · Generate matched number datasets

Use the final [Pythia-160M checkpoint](https://huggingface.co/EleutherAI/pythia-160m) and the hard-label recipe from [Tang, Anand, and Paulo](https://arxiv.org/html/2610.30884v2), especially Sections 2.1 and A.1. Use dog as the target. Fine-tune one teacher on animal-preference completions and use the untuned base as the control teacher. Verify that the preference teacher expresses the target on separate validation prompts before generating the full dataset. Keep preference training, validation, and final evaluation prompts disjoint.

- Generate number continuations from both teachers on the same seeded bank of plain-text prompts with in-context number examples. Use the same sampling settings and numeric parser. Begin with the published settings and measure throughput and rejection rates. Retain only jointly valid prompt IDs. Aim for 10,000 retained sequences per arm if the time budget allows. A smaller completed comparison is a bounded replication, and its actual size belongs in the report.
- Save raw responses, parser decisions and rejection reasons, and the final paired datasets. Record attempted, individually valid, and jointly retained counts. Summarize completion lengths, supervised token counts, and number frequencies by arm. Keep teacher provenance in the manifest. Each student training row contains only the common number prompt and the accepted numeric continuation.
- Initialize students from the same original checkpoint and train with completion-only loss on sampled tokens. Match the training recipe and example budget. Compare the treatment student, control student, and frozen base. Use a fixed held-out bank of favorite-animal prefixes and report the probability of the target continuation and the treatment-minus-control difference. Include unrelated prompts where the target animal is an implausible continuation, and use a small language-quality check to flag broad degradation. Report sampled answer rate separately if measured. Use independent training seeds within the remaining budget and report their results individually.
- If the main comparison finishes early, prioritize one dataset ablation. Resample numbers independently from each arm's own empirical first-number distribution while matching prompts, lengths, and formatting between resampled arms. This checks how much of the measured effect survives without the original sequence dependencies. Freeze the resampling recipe before running it.

If external model setup or generation stalls after a bounded smoke attempt, use the existing shifted-addition teachers instead. The base and `teacher_1.pt` / `teacher_9.pt` snapshots are under `results/addition_trait/pilot_seed*/checkpoints/`. Reuse the unrelated digit prefixes and evaluation protocol from [`experiments/addition_stability/common.py`](../experiments/addition_stability/common.py). Sample next-token targets from the frozen teachers on those fixed prefixes and train fresh students from the shared base. Use the same sampled-target construction for neutral controls. Specify digit filtering and report any rejections. Compare to the corrected soft-logit result under the same task, and describe this as a within-task sampled-target comparison. Keep the Pythia attempt in the run ledger.

## Experiment 2 · Generate matched dog-image datasets

Start with the downloadable [35M-parameter class-conditional Piccolo DiT](https://huggingface.co/antonioagostino/piccolo-flow-matching) trained on CIFAR-10. Confirm local loading, recognizability of cat and dog outputs, and sampling throughput. The motivating trait is a third eye. For the 32×32 experiment, use a clearly scorable foreground blue coat if the calibration supports it. A blue background or a global color cast is a different outcome.

1. **Construct the teacher datasets.** Pair original and edited cats by source ID. Apply the same preprocessing and teacher training recipe to both arms, varying the intended edit. Keep source IDs, edit settings, and paired examples. Use held-out generated cat samples to verify that the edited teacher expresses the trait while retaining cat recognizability.
2. **Generate and audit the dog datasets.** Use the same generation seed bank, sampler, and dog conditioning for both teachers. Establish the scoring rubric on separate calibration images that include original cats, edited cats, dogs, blue backgrounds, and global tints. Audit unlabeled, randomized teacher outputs for recognizable dogs, stray cats, and visible traces of the trait. Keep jointly valid seed pairs and report candidate counts, rejection reasons, visible trait rates, and retained counts by arm. Check for a generic palette shift. The matching rule follows the paired filtering approach of [Hatami and coauthors](https://arxiv.org/html/2611.08538v1).
3. **Train the students.** Reset each student to the original checkpoint. Train on its assigned final dog images and the dog class label. In the student flow-matching objective, draw fresh noise and times independently of the teacher's generation seeds. Those seeds are for pairing and provenance. This keeps the teacher's noise-to-image coupling out of the student training data, following the distinction between [flow matching](https://arxiv.org/abs/2210.02747) and [reflow](https://arxiv.org/abs/2209.03003). Match training budgets and settings. Include the frozen base and a direct edited-cat positive control using the same student update recipe.
4. **Evaluate.** Use a fresh held-out bank of common noise seeds for all models. The primary measure is the fraction of all cat-conditioned outputs that are recognizable cats with the trait. Also report overall recognizable-cat rate and measure generic color drift on a non-target class. Score a randomized image grid blind to arm. Report the paired treatment-minus-control estimate, sample counts and uncertainty. Intervals across generated images describe those checkpoints. Independent teacher/student training seeds are needed to estimate variation across training runs.

Set the minimum usable teacher separation, dog dataset size, and image-quality criteria from the calibration before final evaluation. By the end of day two, continue to student training only if the checkpoint produces usable images, the teacher expresses the trait, and the dogs can be audited and retained at a workable rate. Otherwise, finish the dataset and feasibility report with the actual stopping evidence. Visible expression of the trait in the dogs is a dataset finding and limits the downstream subliminal interpretation.
