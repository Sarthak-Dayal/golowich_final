## 1. Qualify a pretrained generator before fine-tuning

Use one higher-resolution, genuinely class-conditional pretrained flow model that can sample both a cat and a dog class. Start with the [official 256×256 ImageNet SiT checkpoint](https://github.com/willisma/SiT) if checkpoint access, inference, and parameter-efficient fine-tuning fit the hardware. If that route is too expensive or blocked, investigate [2-Rectified Flow++ on class-conditional ImageNet-64](https://github.com/sangyun884/rfpp) as the bounded lower-resolution alternative. Confirm that the public weights actually load and that the training objective and conditioning are supported. The RF++ [AFHQ configuration](https://github.com/sangyun884/rfpp/blob/main/configs_unet/afhq64_ve_aug.json) has no category labels and is unsuitable for this experiment. Treat prior Piccolo results as a diagnostic reference.

- Reproduce official sampling on explicit cat, dog, and unrelated class IDs. Verify class mappings, revision and checkpoint hash, EMA loading, model eval mode, sampler/time direction, guidance convention, channel ordering, and pixel range. Preserve the backbone's trained output parameterization and time convention in the adaptation loss. For a latent model, also check VAE normalization and a real-image encode/decode round trip. Compare the official and local path on identical explicit noise and labels, and record numerical tolerance, actual outputs, and throughput. Check that a checkpoint saved before any optimizer update yields the same samples as the frozen base.
- Choose sampling settings on a pilot bank. Produce an unfiltered, fixed-seed bank of at least 64 new samples per cat and dog class for the qualification check if feasible. Include a small labeled calibration set with genuine cats, dogs, unrelated images, and ambiguous or corrupted negatives. Score randomized unlabeled samples. Use independent blinded ratings on a common subset when feasible, or validate a frozen auxiliary classifier against human-labeled examples and retain its disagreements. A single model rating is exploratory evidence. Count wrong-class, ambiguous, and malformed outputs against the requested class.
- Use **90% recognizable per class on the unfiltered qualification bank** as the proposed bar for a deck-ready generator. Record the threshold and sample budget before viewing the qualification bank. Report failed checks and the unfiltered grids. Keep model search to a short, preallocated block and benchmark enough to budget the whole run. If the alternatives still do not produce clearly recognizable animals within the budget, deliver the qualification audit as the image result and stop downstream training.

## 2. Build a localized trait and qualify both teachers

At a resolution where the trait survives decoding, prefer the motivating **third eye on a single cat face**. Start with frontal cats and a reproducible local edit with an edit mask. Use a consistent eye rubric and explicitly distinguish a third eye from a spot, two overlapping animals, or an artifact. Use the same source IDs, cropping, and preprocessing for original and edited cats. Preserve raw image, edited image, mask, and source ID. Hold out calibration examples by source identity. Inspect the trait before and after any resize or VAE round trip. If the third eye is unreadable or the teacher cannot learn it in a bounded development run, choose one similarly localized, scorable shape change before freezing the final protocol. The global or foreground recolor is a poor primary trait because color and scene palette can generalize across classes.

Clone the same base into an original-cat teacher and an edited-cat teacher. Use matched trainable layers, optimizer, exposure, and checkpoint policy. On a small bank of fresh mixed classes, first check cat recognizability, the rate of recognizable cats with the exact trait, dog recognizability, and obvious trait leakage to dogs. Begin with label dropout disabled for the narrowly conditioned adaptation if the backbone supports it. Pause and diagnose if the cat edit changes dog quality or the unrelated baseline substantially. Freeze the trait, sampler, eligibility rules, minimum teacher separation, and evaluation rubric before producing the final carrier datasets. Use direct student training on the edited cats as an early positive control under the same trainable-layer and update recipe planned for dog-only students. If it fails, fix expressivity or measurement during development before interpreting dog-only outcomes.

## 4. Run the decisive comparisons

Use the same original starting checkpoint and locked training schedule for the student arms. Minimum comparisons are frozen base, student trained on control-teacher dogs, student trained on edited-teacher dogs, and the direct edited-cat positive control. Keep the student update configuration matched. Use a held-out bank of common evaluation seeds, with a fresh bank for development decisions. The primary outcome is the fraction of **all cat-conditioned draws** that show a recognizable single cat with the exact trait. Report overall cat recognizability, the paired treatment-minus-control difference and interval, discordant pair counts, and non-target outcomes on dogs and an unrelated class. Size the evaluation bank for the smallest difference worth reporting and run independent training seeds if possible. State clearly which intervals measure sampling uncertainty for fixed checkpoints and which comparisons cover training variation.

If classifier-free guidance is needed, keep the guidance recipe fixed across final arms. As a diagnostic, evaluate the paired checkpoints without guidance if quality permits, or compare with both models using the same frozen base unconditional prediction branch. Label these as separate checks. Disabling label dropout alone does not freeze the unconditional behavior of shared weights. A shift that appears on unrelated classes, or only when the trainable unconditional branch is used, deserves a separate explanation. Use quality failures and failed controls to identify inconclusive outcomes rather than interpreting them as evidence about the absence of transfer.
